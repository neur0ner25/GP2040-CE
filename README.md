## О проекте

**ProBridge-S2** — специализированная прошивка для платы **Waveshare RP2040-Zero**, обеспечивающая прямое подключение геймпадов **8BitDo** (через комплектный 2.4G-ресивер или проводное USB-подключение) к консолям **Nintendo Switch и Switch 2** в режиме нативного проводного **Switch 2 Pro Controller** (`057E:2069`).

---

## Главные преимущества перед оригинальным проектом

1. **Детерминированный цикл 1000 Гц без задержек памяти (Zero Flash Latency)**
   - Критический конвейер приёма ввода USB Host и формирования исходящих HID-отчётов полностью выполняется из оперативной памяти (SRAM).
   - Исключены микрозадержки и джиттер, вызываемые кэш-промахами внешней flash-памяти (XIP) во время игры.
   - Из горячего пути устранены вызовы внешних функций стандартной библиотеки (`memcpy`/`memcmp`) и «тяжёлая» 64-битная арифметика.

2. **Математическая компенсация стиков Hall / TMR**
   - Устранено межосевое магнитное затухание на диагоналях ($45^\circ$), характерное для датчиков Холла и TMR в контроллерах 8BitDo.
   - Интегрирована нелинейная эллиптическая нормализация, гарантирующая полный круговой охват ($100\%$ диапазона) во всех 8 направлениях без срезания диагоналей.

3. **Двухчастотный кроссовер тактильной отдачи (HD Rumble → ERM)**
   - Потоковое декодирование HD Rumble пакетов консоли с разделением на низкочастотный (LF) и высокочастотный (HF) спектры.
   - Динамический стартовый импульс (kickstart / overdrive) для преодоления трения покоя стандартных эксцентриковых моторов (ERM) — вибрация срабатывает резче, чётче и без смазывания фронтов.

4. **Энергонезависимая системная калибровка стиков Switch 2**
   - Полная поддержка штатной калибровки из системного меню Nintendo Switch: консоль считывает и записывает калибровочные профили через Vendor-команды (`0x02`, виртуальный адрес `0x1FC000`).
   - Данные сохраняются во flash-памяти контроллера и сохраняются при перезагрузках и отключениях питания.
   - Межъядерная синхронизация на атомарных флагах гарантирует надёжную запись без пауз и микрофризов в основном игровом цикле.

5. **Нативная эмуляция Nintendo Switch 2 Pro Controller (`057E:2069`)**
   - Корректная обработка всех системных протоколов консоли: NFC / Amiibo handshake, криптографический обмен ключами Bluetooth LTK (AES-128), индикация номера игрока.
   - Статичный неизменный профиль сопряжения — консоль распознаёт контроллер мгновенно и не создаёт дубликатов устройств.

## Схема подключения (Waveshare RP2040-Zero)

```
                  ┌────────────────────────┐
                  │  Waveshare RP2040-Zero │
                  │                        │
   [К Switch 2]   │ USB-C (Native USB)     │ ──> Device (Core 0, 1000 Гц)
                  │                        │
   [К ресиверу    │ GP28 ──────> USB D+    │ ──> Host (Core 0, Pico-PIO-USB)
    8BitDo 2.4G]  │ GP29 ──────> USB D-    │
                  │ 5V   ──────> USB VBUS  │
                  │ GND  ──────> USB GND   │
                  │                        │
                  │ GP16 ──────> RGB LED   │ ──> Статусный индикатор (Core 1)
                  └────────────────────────┘
```

## Сборка и прошивка

### Требования
- `arm-none-eabi-gcc`, `arm-none-eabi-newlib`, `cmake`, `make`
- [Raspberry Pi Pico SDK](https://github.com/raspberrypi/pico-sdk) (`PICO_SDK_PATH`)

### Сборка
```bash
./build.sh
```
Готовый бинарный файл: `build/ProBridge-S2_0.7.12_WaveshareZeroDongle.uf2`.

### Установка
1. Зажмите кнопку **BOOT** на плате RP2040-Zero и подключите её к компьютеру.
2. Скопируйте файл `.uf2` на появившийся съёмный диск **RPI-RP2**.
